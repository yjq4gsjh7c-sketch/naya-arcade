# Atelier art
Generated with the built-in image generation tool, using the approved Nayas Atelier mockup as visual reference. Final assets: room.webp, dolls.webp, feet.webp, reference.webp in this folder. WebP encoding preserves transparency for the sprite atlases. Runtime canvas crops atlas cells and recolors hair/socks.

Prompt set (production specifications):
- Room: recreate the reference dressing room, same warm pastel, rendered family-game aesthetic; remove girl and all UI, leave room as a clean landscape background.
- Dolls: transparent 2×2 sheet; same original girl, face, pose, hair, proportions and full-body framing in each cell; purple flower cardigan/pink skirt, yellow flower dress, mint overalls, coral flower cardigan/pink skirt. No text, UI or backdrop.
- Feet: transparent 2×2 sheet of matching lower legs and mint striped socks; purple sneakers, coral floral Mary Janes, mint sneakers, yellow floral flats. Same rendered aesthetic, no text or backdrop.
- Reference: approved landscape German dress-up game concept named Nayas Atelier, warm pastel dressing room, original cute stylized female doll, cream wardrobe tiles, large picture-led touch controls, clothing/hair/shoes/jewelry/colors/food categories.

The character is raster artwork with a 3D rendered appearance, not an interactive 3D mesh.
